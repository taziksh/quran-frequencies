Quran Word Frequency Counter

Count occurrences of specific Arabic words in the Quran using the Quranic Arabic Corpus morphology file (v0.4), downloadable from https://corpus.quran.com/download/

The JQuranTree Java API (https://github.com/dsog/jqurantree) can also be used for cross-validation.

For each word below, count occurrences using every reasonable method: by lemma, by root, by POS filter (noun, adjective, proper noun, verb), by number (singular vs plural/dual), and combinations thereof. Report all counts.

Morphology file format:
- Tab-separated: LOCATION, FORM, TAG, FEATURES
- Lines starting with # are comments
- Only FEATURES starting with "STEM" are word entries
- FEATURES has pipe-separated fields like: STEM|POS:N|LEM:d~unoyaA|ROOT:dnw|FS|GEN
- POS = part of speech, LEM = lemma, ROOT = trilateral root
- Buckwalter transliteration is used (^ = maddah, ~ = shadda)

For roots with multiple derived words, list all lemmas under that root with their counts.
